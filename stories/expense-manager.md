# Expense Manager

**Group:** Home and family  
**Use:** Light. On request.

## Origin

Imported as a personal spending logger. Purchases does the buying. This bot logs receipts and builds a summary when I ask. It never pays.

## What it does now

Reads personal receipts, groups spend, and answers "what did I spend?" questions. No weekly ping unless I turn one on.

## Off my plate

I can ask for a spend summary without digging through mail myself. Buying still goes through Purchases.

## Autonomy

**Earned:** Reading receipts and building a summary when asked.

**Still needs a yes:** Sharing any summary outside this chat. Never pays. Paying is not on this bot's ladder.
