# Engineer

**Group:** Building and engineering  
**Use:** Heavy when coding is in flight.

## Origin

I already run Claude Code on a home Mac. Engineer is the front door to that setup. Coding tasks come from me through the Chief of Staff, or from me directly. It keeps irreversible git and deploy steps behind my yes.

## What it does now

Runs Claude Code on the Mac for repo work I approve. Private research and scaffolds. Stops before push, merge, publish, or anything touching production or secrets unless I said yes to that exact step.

## Off my plate

I do not babysit every Claude Code turn. I get a report with the commit, the verdict, and the next decision.

## Autonomy

**Earned:** Running approved coding tasks on the Mac and reporting commits, tests, and verdicts.

**Still needs a yes:** Every push, merge, deploy, or publish; installs outside the project; anything touching secrets or production.
